# Mods YOU (the player) can add — all of them optional

## The short version

> **You do not need to install anything to join.** Patchee runs on the server.
> A client without it is out of step with the server wherever Patchee changes
> something; the list below says what each one does for your own game.
> Everything here is optional.

## The optional list

These are allowed on the server, and each one only changes things on **your** computer.

| Mod | What it does for you | Do you need it? |
|---|---|---|
| **Patchee** (this mod) | Makes your own game match the server: the tank effects are cleared on your screen too, and sand and snow break at the speed the server uses. It also makes NEI's F7 light overlay mark only pitch-dark blocks instead of NEI's fixed levels. Without it, those are out of step (your screen still shows the tank effects, you move slower than the server expects, and F7 marks more blocks than can really spawn). | Only if you want your client in step with the server. |
| **VeinMiner** (client side) | Adds the vein-mining hotkey and a settings menu. The server runs VeinMiner too; **without** your client copy you can still vein-mine — type `/veinminer mode sneak` once (again after a server restart), then sneak while mining. | Only if you prefer a hotkey over sneaking. Get the Minecraft **1.7.10** file (VeinMiner 0.36.0) from its CurseForge page. |

*(More optional client mods will be listed here as we add them. Nothing here is required to join.)*

## How to add a client mod safely

1. **Close Minecraft.**
2. Open **your instance's** `mods` folder (right-click the instance → Open folder → `mods`). This is **not** the server's folder.
3. Put the new `.jar` in. Do **not** unzip it.
4. Start the game.

**Three rules that keep you out of trouble:**

- Only use mods made for **GTNH / Minecraft 1.7.10**. A mod for a newer Minecraft will crash your game.
- Never **replace** a mod the pack already has with a different version — add only what is missing.
- If two files say the same mod name, keep only the newest.

## Why this page exists

We collect the "nice to have but not required" mods here so nobody has to guess. If you want something added to the list, ask an admin first — the server sets the rules.
