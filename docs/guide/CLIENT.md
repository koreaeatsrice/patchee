# Mods YOU (the player) can add — all of them optional

For a player or owner deciding whether to put Patchee on a client. It lists what a client copy adds, what it does not, and which mods are optional.

## The short version

> **You do not need to install anything to join.** Patchee runs on the server.
> A client without the jar is out of step with the server only where a fix changes
> something on the server that your game can see — sand and snow break at the old
> speed, for example. The tank debuffs are **not** on that list: a stock client is
> in step because the server leaves GregTech's own debuff and timer alone, so it
> wears off as it always did (up to ten minutes after you put the tank down).
> The list below says what each fix does for your own game.
> A client copy is also what brings NEI's F7 light overlay and the Twilight
> Forest break speeds to your own game; without it you just keep the plain
> 1.7.10 break speeds for those blocks, with no mismatch. Blocks built into
> microblocks, shapes, covers or tiles follow the same rule.
> Everything here is optional.

## The optional list

These are allowed on the server, and each one only changes things on **your** computer.

| Mod | What it does for you | Do you need it? |
|---|---|---|
| **Patchee** (this mod) | Makes your own game match the server: the tank debuff is cleared on your screen — without the jar that debuff is GregTech's own and in step, because the server leaves its debuff and timer alone, so it wears off as it always did (up to ten minutes after you put the tank down) — and sand and snow break at the speed the server uses. It also makes NEI's F7 light overlay mark only pitch-dark blocks instead of NEI's fixed levels. With **InventoryBogoSorter** installed, the Fish Trap's move hotkeys (space/alt/ctrl-click) work from the server jar alone; sorting the trap's output with middle-click (and the sorter's sort button in that GUI) needs Patchee on the client too. It also makes the IC2 Quantum Chestplate rise and sink at the same speed in hover mode, makes the GraviSuite jetpack rise and sink at the same speed in hover mode, and holds your height when you press sneak and jump together (it no longer climbs on IC2 or sinks on GraviSuite). Those mods send your key state to the server, so that half works on both sides; the same jar on your client keeps the two in step. Without it, the only parts out of step are sand and snow break speed, and F7, which marks more blocks than can really spawn. The two sides must agree: the server clears for any player whose client reports Patchee, whatever that client's own setting is, so turning the client setting off alone leaves you seeing a debuff the server has already cleared. | Only if you want your client in step with the server. |
| **VeinMiner** (client side) | Adds the vein-mining hotkey and a settings menu. The server runs VeinMiner too; **without** your client copy you can still vein-mine — type `/veinminer mode sneak` once (again after a server restart), then sneak while mining. | Only if you prefer a hotkey over sneaking. Get the Minecraft **1.7.10** file (VeinMiner 0.36.0) from its CurseForge page. |

*(More optional client mods will be listed here as we add them. Nothing here is required to join.)*

## How to add a client mod safely

1. **Close Minecraft.**
2. Open **your instance's** `mods` folder (right-click the instance → Open folder → `mods`). This is **not** the server's folder.
3. Put the new `.jar` in. Do **not** unzip it.
4. Start the game.

**Three rules that keep you out of trouble:**

- Only use mods made for **GTNH / Minecraft 1.7.10**. A mod for a newer Minecraft will crash your game.
- Never **replace** a mod the pack already has with a different version — add only what is missing.
- If two files say the same mod name, keep only the newest.

## Why this page exists

We collect the "nice to have but not required" mods here so nobody has to guess. If you want something added to the list, ask an admin first — the server sets the rules.
